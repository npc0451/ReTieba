# ReTieba 1.0.0-rc.1

**Pure Tieba Reader**。首个本地发布候选版，基于 TiebaPure-Android 改造。

## 功能范围

- 免登录只读：推荐、进吧、搜索、帖子、楼中楼与公开用户资料。
- 本地贴吧订阅、用户关注、来源与时间范围筛选、已加载帖子排序。
- 书签、历史、阅读位置和独立离线保存，明暗主题及系统／Plex／导入字体。
- 本地屏蔽、图片保存、媒体阅读、平板列表／详情布局。

## 首版收尾

- 使用提供的“贴”字图标，适配旧版与自适应桌面图标。
- 点赞轮廓改为圆润肩角与 U 形弧底，继续只显示真实数量。
- 压低统计、分享和订阅胶囊的视觉高度，保留点击区域；订阅与竖三点操作向末端微移。
- 进吧页最近浏览支持长按、取消或移除；移除持久化记录，不取消订阅。
- 浅桃等级标签与橙红楼主标签区分；正文、姓名、吧名和标题使用统一字体选择。
- 图片恢复上游单图最大尺寸；评论预览与“查看回复”文字对齐，主楼与评论区保留横向分隔带。

## 候选版边界

当前仅准备本地安装包、源码和发布资料，不创建或发布远程仓库。可安装 candidate APK 使用既有开发签名，便于更新开发版；长期公开签名尚未配置时，Release APK 为 unsigned，不可直接安装。正式公开发布须按[发布指南](../RELEASING.md)确认签名与迁移方式。

订阅排序只针对已加载内容，不是完整热榜。接口可用性受服务端变化影响。没有连接测试设备，原生测试执行、帧时间、明暗截图和平板交互仍待实机验证；测试与构建结果以随包验证记录为准。
