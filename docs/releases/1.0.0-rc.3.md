# ReTieba 1.0.0-rc.3

Pure Tieba Reader 的首次公开预发布版。支持 Android 6.0 及以上，使用 Kotlin 与 Jetpack Compose，基于 TiebaPure-Android 改造。

## 功能

- 匿名浏览推荐、搜索、贴吧帖子、评论与楼中楼；点赞只展示真实数量。
- 本地订阅贴吧与关注用户；订阅流按来源、时间范围筛选，可按发布、最后回复时间或已加载帖子的热度排序。
- 本地收藏、历史、阅读位置恢复与独立离线保存；图片查看和保存、视频播放。
- 用户／贴吧／关键词屏蔽、最近浏览长按移除、缓存管理。
- 明暗主题、阅读字号与行距、内置 Plex 及导入字体；手机、平板双栏与分屏布局。
- 吧内帖子整张卡片可点击打开；头像与图片保留独立操作。

## 安装

下载本页附件 `ReTieba-1.0.0-rc.3-candidate.apk`，可使用 `SHA256SUMS.txt` 校验。版本码 25，应用 ID 为 `dev.infinityf4p.tiebapure.reader`。本次沿用开发签名，可覆盖此前同签名的 ReTieba 开发版；不覆盖上游应用。正式签名尚未确定。

## 范围与限制

- 订阅、关注与收藏保存在本机，不与贴吧账号同步；聚合排序只覆盖已加载帖子，不是全吧完整榜单。
- 应用通过关闭账号写入口、切断调用和 API 请求拦截实现只读，部分上游源码仍保留。
- 当前没有连接测试设备，本次无法执行实机回归；手势流畅度、设备间字体与媒体兼容性仍需反馈。

源码与必要许可随对应标签公开。感谢 [TiebaPure-Android](https://github.com/infinityf4p/TiebaPure-Android) 及其作者，沿用 GPL-3.0-only。
